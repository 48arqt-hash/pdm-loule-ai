# Métricas internas adiadas

A base Neon atualmente ligada ao projeto devolve `project not found`. Para não
afetar a pré-análise, os e-mails, os pedidos de reunião ou os pedidos de
orçamento, as métricas internas ficam desligadas por predefinição.

Não é necessário alterar ou apagar as variáveis atuais na Netlify. Quando o
site tiver uso regular, criar ou ligar uma nova base e definir
`ENABLE_OPERATION_METRICS=true`. Até lá, o acompanhamento operacional é feito
pelos e-mails enviados para `geral@leonelmendes.com`.
