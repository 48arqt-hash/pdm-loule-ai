# Confirmação visual do modo profissional

Depois de validar o código, o site passa a mostrar no painel de pré-análise um
aviso verde permanente: **Modo profissional ativo**. O campo do código fecha-se
automaticamente para indicar que a validação terminou.

O estado é válido para a sessão do browser. Se a sessão expirar, basta validar
o código novamente.
